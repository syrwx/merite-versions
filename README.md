# Mérite — versions publiées

Ce dépôt ne contient **pas de code**. Il ne sert qu'à héberger les installateurs de
**Mérite**, le logiciel de gestion de l'École Privée le Mérite (ECO.PRI.ME, Niamana).

Les versions sont dans l'onglet **[Releases](../../releases)**.

## Pourquoi ce dépôt est public

L'application vérifie elle-même s'il existe une version plus récente. Si ce dépôt était
privé, il faudrait enfermer un mot de passe GitHub dans le logiciel installé à l'école —
et n'importe qui pourrait l'en extraire. Un dépôt public ne contient que ce qui est déjà
distribué : les installateurs.

Le code, lui, reste privé.

## Installer

`Merite-Setup-<version>.exe` — Windows 64 bits.

La **première** installation se fait à la main, par clé USB. Ensuite, le logiciel annonce
lui-même les nouvelles versions : il ne télécharge et n'installe jamais rien sans qu'on le
lui demande.

Windows affichera « Éditeur inconnu » : le logiciel n'est pas signé par un certificat
commercial. Cliquez sur **Informations complémentaires → Exécuter quand même**.
